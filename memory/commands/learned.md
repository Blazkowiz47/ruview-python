# Command: /learned

Record a durable finding or reusable lesson.

## Steps

1. Add the finding to `memory/learnings.md` under the most appropriate section.
2. Add supporting context or evidence paths, not bulky raw output.
3. If the stable `<node>` name is not known, ask the user for it before creating or writing a new node-specific note.
4. Add a short entry to today's project note, preferring `memory/notes/YYYY-MM-DD-<node>.md` for new notes.
5. If the learning changes the current framing, blocker, or next action, update `memory/index.md`.
