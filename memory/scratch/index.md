# Scratch

Project-local scratch is for uncertain captures and in-flight notes that belong to this project but are not ready for `notes/`, `runs.md`, `learnings.md`, `decisions.md`, or `index.md`.

## Rules

- Use one topic per file, for example `dataset-consistency.md`.
- Include date, node/device if known, source paths, current question, evidence links, and next action.
- Link to bulky logs, outputs, commits, and artifacts instead of pasting them.
- Promote durable outcomes into the structured memory files and delete or mark the scratch file closed when finished.
